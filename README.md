# Resume Template (Vite + Vue 3)

Шаблон резюме на Vue 3 и Vite, готовый для публикации как публичный темплейт GitHub. Подходит для быстрого старта персональной страницы с резюме и портфолио.

## Возможности
- SPA на Vue 3 с маршрутизацией (`vue-router`)
- Стилизация через Tailwind и кастомные CSS
- Поддержка тёмной темы
- Принт/экспорт в PDF через `html2canvas` и `jspdf`
- Готовые favicon/manifest ресурсы

## Требования
- Node.js 18+ (рекомендуется LTS)
- npm (используем `package-lock.json`)

## Установка и запуск
```bash
npm install          # установка зависимостей
cp env.example .env  # скопируй и при необходимости поменяй значения
npm run dev          # локальная разработка
```

## Переменные окружения
Создавай `.env` из `env.example` и указывай свои значения:
- `VITE_ALLOWED_HOSTS` — список хостов для dev/preview (через запятую). Значение `all` разрешает все хосты (удобно для PM2/Netlify).
- `VITE_MAIN_FRONTEND_DOMAIN` — домен для фронтенда. Не хардкоди адреса в коде, всегда используй переменные окружения.

## Сборка и предпросмотр
```bash
npm run build   # прод-сборка
npm run serve   # предпросмотр собранной версии на порту 4011 по умолчанию
```

## Тесты
```bash
npm test
```

## Деплой
- Netlify: конфиг уже в `netlify.toml` с редиректом на `index.html`.
- PM2: см. `ecosystem.config.js`; значения порта и доменов берутся из окружения.
- Для прод-старта через PM2 можно задать, например:
  ```bash
  VITE_ALLOWED_HOSTS=resume.rudin.ru,localhost
  VITE_MAIN_FRONTEND_DOMAIN=https://resume.rudin.ru
  ```
  PM2 читает `.env` через `dotenv`, зависимость есть в `package.json`.

## Использование как шаблон
1. Нажми “Use this template” на GitHub.
2. Создай репозиторий из шаблона.
3. Настрой `.env` под свой домен и хосты.
4. Собери и задеплой.

## Структура
- `src/` — исходники приложения (компоненты, роутер, стили).
- `public/` — статика и манифест.
- `env.example` — пример окружения.
- `ecosystem.config.js` — конфиг для PM2.
